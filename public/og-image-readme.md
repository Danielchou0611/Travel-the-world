# OG Image 待補

需要產出 `og-image.jpg`(1200×630)放在 `public/` 根。

## 推薦快速做法(3 分鐘)

1. 開啟 `http://localhost:5173/brand_preview.html` 在 Chrome
2. 視窗調到 1200 寬,scroll 到首屏 Hero(富士山 + Occupath logo)
3. `Cmd+Shift+4` 區域截圖,選 Hero 區
4. macOS 內建預覽程式 → 調整大小到 1200×630 → 匯出 JPG → 命名 `og-image.jpg`
5. 放進 `public/og-image.jpg`

# pipeline-restaurant

日本餐廳資料的獨立轉換工具。

目前保留 4 個腳本：

- `build_japan_restaurants.py`
  把原始餐廳 JSON 整理成標準化 CSV 與評分後 CSV
- `simplify_restaurant_interest_json.py`
  把 scored CSV 轉成較適合推薦使用的餐廳 JSON
- `run_restaurant_pipeline.py`
  一次跑完整的餐廳推薦資料流程，直接輸出 `interest.json`
- `csv_to_json.py`
  把任意 CSV 直接轉成 JSON

## 1. build_japan_restaurants.py

用途：

- 讀取原始餐廳 JSON
- 整理欄位格式
- 補 prefecture / category / lat / lng
- 產生標準化資料與評分後資料
- `static_score` 只依照 `google_rating` 與 `review_count` 計算
- 過濾明顯不是餐廳的資料

用法：

```bash
python3 build_japan_restaurants.py ../raw-data/restaurant/日本全_v1_with_rating.json ./output
```

輸出檔名預設會用 input 檔名 stem：

- `<stem>_normalized.csv`
- `<stem>_scored.csv`
- `<stem>_pipeline_report.json`

例如：

```bash
python3 build_japan_restaurants.py ../raw-data/restaurant/日本全_v1_with_rating.json ./output
```

會產生：

- `output/日本全_v1_with_rating_normalized.csv`
- `output/日本全_v1_with_rating_scored.csv`
- `output/日本全_v1_with_rating_pipeline_report.json`

參數：

- `input_json`: 原始 JSON 路徑
- `output_dir`: 輸出資料夾
- `--prefecture-lookup`: 自訂 lookup CSV；預設使用 `reference/source_id_metadata_lookup.csv`
- `--prefecture-json-dir`: 指定各縣市 JSON 資料夾，會用檔名當 prefecture 回填地區
- `--source-prefecture`: 當輸入是一個單一縣市 JSON 時，直接指定整份資料的 prefecture
- `--output-prefix`: 自訂輸出檔名前綴

支援的原始 JSON 欄位：

- `id` 或 `source_id`
- `name`
- `type` 或 `category`
- `coordinates`，格式如 `Point(136.489825 35.012782)`
- `lat` / `lng`
- `google_rating`
- `google_review_count`
- `google_name_matched`
- `image` 或 `image_url`

補充：

- 如果輸入檔旁邊存在 `japan_data_v1_with_rating/`，腳本會自動把那個資料夾當成各縣市 lookup 來源
- 如果輸入本身就是 `japan_data_v1_with_rating/東京都.json` 這種單一縣市檔案，腳本會自動把檔名當成 prefecture
- 仍會保留 `station_anchor`、`distance_to_station_km`、`station_distance_efficiency`
- 但這三個欄位不再參與 `static_score`
- pipeline report 會額外記錄 `excluded_non_restaurant_rows`

過濾規則：

以下明顯非餐飲類型會在 build 階段直接排除，不進入後續分類與排序：

- 住宿：`ホテル`, `ビジネスホテル`, `リゾートホテル`, `カプセルホテル`, `旅館`, `ゲスト ハウス`, `民宿`
- 景點與宗教：`観光名所`, `神社`, `仏教寺院`, `寺院・礼拝所`, `公園`, `景勝地`, `史跡`
- 交通與休息站：`駅`, `駅 / 停留所`, `地下鉄駅`, `モノレール駅`, `サービスエリア / パーキング エリア`
- 購物與零售：`ショッピング モール`, `スーパーマーケット`, `マーケット`, `ファーマーズ マーケット`, `雑貨店`
- 非餐飲服務：`タイ マッサージ セラピスト`, 含 `マッサージ` 的類型, `企業のオフィス`, `結婚式場`, `ライブ会場`
- 夜生活場館：`ナイトクラブ`, `ジャズ クラブ`, `キャバレー クラブ`
- 其他非餐廳場域：`農場`, `果樹園`, `ディスカウント ストア`, `ワイナリー`

評分公式：

```text
static_score = 0.7 * rating_norm + 0.3 * review_norm
```

## 2. simplify_restaurant_interest_json.py

用途：

- 讀取餐廳 scored CSV
- 把原始 `type` 收斂成中文 `category`
- 新增 `venue_type`：`小店` / `餐廳`
- 產生推薦可用的 `interests` 陣列
- 在 `interests` 中保留中文化後的細分類，例如 `和菓子`、`蛋糕`、`燒鳥`

用法：

```bash
python3 simplify_restaurant_interest_json.py output/日本全_v1_with_rating_scored.csv output/日本全_v1_with_rating_interest.json
```

輸出欄位：

- `id`
- `name`
- `region`
- `category`
- `venue_type`
- `interests`
- `google_rating`
- `review_count`
- `station_anchor`
- `distance_to_station_km`
- `rating_norm`
- `review_norm`
- `station_distance_efficiency`
- `static_score`
- `image_url`
- `lat`
- `lng`
- `google_name_matched`
- `raw_type`

interest 規則包含：

- `venue_type=小店` -> 加 `小店`
- `venue_type=餐廳` -> 加 `餐廳`
- `カフェ`, `喫茶`, `コーヒー` -> 加 `咖啡廳`
- `甜點/菓子/ケーキ/アイス/クレープ` -> 加 `甜點`
- `居酒屋`, `焼肉`, `火鍋`, `ビュッフェ`, `レストラン` -> 加 `聚餐`
- `フランス料理`, `イタリア料理`, `ビストロ`, `ワインバー` -> 加 `約會`
- `居酒屋`, `バー`, `ラーメン`, `焼き鳥`, `おでん` -> 加 `宵夜`
- `テイクアウト`, `軽食`, `ファースト フード`, `サンドイッチ` -> 加 `外帶`
- `バー`, `居酒屋`, `ビアホール`, `ワインバー`, `日本酒` -> 加 `酒類`
- `郷土料理店`, `和菓子屋`, `会席`, `うなぎ`, `海鮮` -> 加 `在地特色`
- `ファミリー レストラン`, `定食屋`, `ビュッフェ` -> 加 `家庭聚餐`
- `ラーメン`, `咖哩`, `蕎麦`, `うどん`, `牛丼/快食類` -> 加 `快速用餐`

分類原則：

- `category` 是收斂後的大類，例如 `甜點`、`日式`、`咖啡`
- `venue_type` 是店型，例如 `小店`、`餐廳`
- `interests` 同時保留情境標籤與中文細分類，例如 `和菓子`

## 3. run_restaurant_pipeline.py

用途：

- 一次執行 `build_japan_restaurants.py`
- 接著執行 `simplify_restaurant_interest_json.py`
- 直接產出餐廳推薦用的 `interest.json`

用法：

```bash
python3 run_restaurant_pipeline.py ../raw-data/restaurant/日本全_v1_with_rating.json
```

預設會輸出：

- `output/日本全_v1_with_rating_normalized.csv`
- `output/日本全_v1_with_rating_scored.csv`
- `output/日本全_v1_with_rating_pipeline_report.json`
- `output/日本全_v1_with_rating_interest.json`

自訂輸入輸出：

```bash
python3 run_restaurant_pipeline.py input.json ./output --output-prefix my_restaurants
```

可選參數：

- `--prefecture-lookup /path/to/lookup.csv`
- `--prefecture-json-dir /path/to/japan_data_v1_with_rating`
- `--source-prefecture 東京都`
- `--output-prefix my_restaurants`
- `--indent 2`

## 4. csv_to_json.py

用途：

- 把 CSV 檔直接轉成 JSON array
- 會做基本型別轉換
- 空字串會轉成 `null`
- 數字會轉成 `int` 或 `float`

預設用法：

```bash
python3 csv_to_json.py
```

預設會讀：

- `output/日本全_v1_with_rating_scored.csv`

自訂輸入輸出：

```bash
python3 csv_to_json.py input.csv output.json
```

可選參數：

- `--indent 2`: pretty print JSON，預設是 2
- `--indent 0`: 輸出壓縮版 JSON
